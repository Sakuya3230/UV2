# 2. ガイドを描くツール

[目次](README.md) ・ 前: [1. ガイドの計算](01_guides.md) ・ 次: [3. シームとカット](03_seams.md)

## 目的

ビューの上でガイドを描き・選び・消せるようにし、シーンに保存する (Undo / Redo も効く)。

## 使い方

```python
import SeamGuide
SeamGuide.tool()     # メッシュを選んでから
```

モードは **作成** と **編集** の 2 つ (2026-10-18 に責務を分けた。ユーザーの要望)。Tab・ビューの下の「作成 / 編集」の
ボタン・ツール設定のウィンドウで切り替え (optionVar に残る)。1〜4 を押すと作成のモードのその種類になる。

| | 作成 (新しいガイドを描くだけ) | 編集 (できているガイドを選んで直すだけ) |
|---|---|---|
| ドラッグ / クリック | ガイドの種類 (1〜4) で描く。ガイドの上のクリックでも選ばない | 選ぶ (Maya と同じ: なし = 置き換え / Shift = 切り替え / Ctrl = 外す / Ctrl+Shift = 足す)。矩形も |
| Ctrl | 15 度刻み | 選択から外す |
| Ctrl+Z | 描いている線の最後の点を戻す (描いていなければ Maya の Undo) | Maya の Undo |
| Delete / Backspace | 描いている線の最後の点を戻す (描いていなければ Maya に渡す) | 選んだガイド (と相手) を消す。カーブの点を選んでいればその点 |
| Esc | 描いている線をやめる | カーブの点の選択 -> ガイドの選択を外す |
| ホイール | **描いたばかりの輪** を平行移動 / Shift で回す (選ばずに動かせる) | 選んだ輪を平行移動 / Shift で回す |
| 選択・ホバーの強調・カーブの点の印 | 出さない | 出す |

描いたガイドは、編集のモードに替えたとき選ばれた状態になる (描いてすぐ Tab で直せる)。「UV をカット」「エッジを選択」は
どちらのモードでも使える。

**ガイドの種類** (作成のモード): キーの **1 リング / 2 フリーハンド / 3 ライン / 4 カーブ / 5 ペイント**、ビューの下のボタン
(「1 リング」などの番号付き)、ツール設定のウィンドウの「ガイドの種類」(フラグ `-guideTool` / `-gt`)。
(以前の「ペイント」= 手描きの補助線は「フリーハンド」に改名し、塗った範囲を囲む新しいものを「ペイント」にした。
Maya でもペイントは面を塗る操作のため)。1〜5 は Maya のホットキー (表示の滑らかさ) と重なるが、ツールの対象があるときはこちらが受け取る。

| 種類 | 操作 | 内容 |
|---|---|---|
| 1 リング | ドラッグ | 輪切りのガイド (描いた線の範囲の断面。ドラッグ中は黄色のプレビューと、対称の相手) |
| 1 リング | Ctrl+ドラッグ | 輪切り。線の向きを画面で 15 度刻みにそろえる |
| 2 フリーハンド | ドラッグ | 補助線 (手描き。レイジーマウス: ひも 20 px。外に出た所で切れる) |
| 3 ライン | クリック | 直線の折れ線の補助線を始める / 点を足す (ドラッグしても離した所に点を置く) |
| 3 ライン | Ctrl+クリック | 区間の向きを 15 度刻みにそろえる |
| 3 ライン | Enter / 最後の点をクリック | 確定 (開いた線。2 点で確定すれば 1 本の直線) |
| 3 ライン | 最初の点をクリック (3 点以上) | 閉じて確定 |
| 3 ライン | Backspace・Delete・Ctrl+Z / Esc | 最後の点を戻す / やめる (ライン以外の種類にしてもやめる) |
| 4 カーブ | クリック | 通る点を置く (ラインと同じく Ctrl で 15 度刻み・確定・閉じる・戻す)。置いた点をすべて通るなめらかな線になる |

| 5 ペイント | ドラッグ / Ctrl+ドラッグ | ブラシで塗る / 消す (**面ごと**: ブラシの円の中に**中心**が入った面を塗る。当たった面は半径が小さくても塗る。Maya のペイント選択の面と同じ考え方)。ブラシの下に、今押したら塗られる面を薄い黄 (Ctrl なら消される面を薄い赤) で見せる (下見。`brushPreviewFaces`)。塗っている間の囲む線は前面に黄 |
| 5 ペイント | (設定) ブラシ | サーフェス (既定) / ボリューム (設定 `brushMode`)。サーフェスは当たった面 (`Surface.faceAt`) から表面に沿った距離で、面の中心が半径の中の面を塗る (`core/region.brush_faces`: 当たった面の頂点までは直線、そこから辺をたどり (dijkstra。表面に沿った距離が半径以内なら 3D の距離も半径以内なので、球の中の頂点だけの小さなグラフ)、最後に頂点から面の中心まで)。すぐ近くでも、つながっていない面・裏側は塗らない。ボリュームは面の中心までの 3D の距離 |
| 5 ペイント | B+ドラッグ | ブラシの半径 (右へ 150 px で 2 倍)。塗らない。Esc で調整前に戻す (`plug-ins/volumeColorBrush.py` と同じ操作) |
| 5 ペイント | > / < | 塗った範囲をブラシの半径の 1/4 (辺の長さの中央値より小さくしない) だけ広げる / 狭める (`core/region.grow_faces` / `shrink_faces`。塗った面・塗っていない面から**表面に沿った距離**で、中心がその距離の中の面。ブラシと同じ測り方。辺 1 つ分ずつだと不規則な三角形では長い辺の所だけ大きく広がってゆがみ、3D の直線の距離だと近くの別の面 (指の間など) に移った。1 筆として Ctrl+Z で戻せる)。塗っていなければ、選んだペイントから塗り直しを始める |
| 5 ペイント | Enter / Ctrl+Z・Backspace / Esc | 塗った範囲を囲む線のガイドにする (対称の相手も) / 1 筆戻す / やめる。ほかの種類・モードに替えても確定する |
| 6 つなぎ線 | クリック | ガイドをクリック (始点) -> (ガイドの無いメッシュのクリック = 中継点) -> 別のガイドをクリック (確定) = その間をエッジの最短パスでつなぐ線。Backspace・Delete・Ctrl+Z = 最後の点を戻す、Esc = やめる。編集で 2 本選んで「つなぎ線」= カメラから見て奥側でつなぐ。詳しくは [04_bridge_spec.md](04_bridge_spec.md) |
| 5 ペイント (ペイントを 1 本選んでから) | 5 で塗り足す・Ctrl で削る -> Enter | そのガイドを塗り直す (1 回の Undo)。全部消すとガイドが消える |

**ペイント** (`core/region.py`・`scene/edit.add_region` / `set_region`。ガイドの種類 REGION): **面ごとに**
塗ったか (0 か 1) を持ち (前は頂点ごとの量で、面の頂点の平均が 0.5 以上の面を範囲にしていたが、円の端の頂点 1 つで
円の外まで広がる面が入り、円を見ても結果が読めなかった。GUI で確認)、**塗った面の境目のエッジ**をつないだ輪を囲む線に
する (`core/region.region_edge_loops` / `painted_faces`: 塗った面の辺を面の向きで並べ、逆向きが塗った面に無い辺が境目。
次々たどって輪にする)。線の点は頂点そのものなので、シームは最短パスで求め直さず頂点の列をそのまま使う
(`core/edge_path.vertex_path`。頂点の上にない前の版の線は従来どおり最短パス)。塗っている間に見える線が確定するシームと
同じなので、どのエッジで確定するかを見ながら塗り足し・消しで調整できる。前は量をならした 0.5 の等高線 (なめらか) にして
いたが、確定でエッジを求め直すので結果が分からず調整しにくかった (GUI で確認)。塗った所が離れていれば線は何本もできる
(ガイドの `loops`。シームも線ごと)。ブラシ (volumeColorBrush と同じ描き方): マウスの下の面に沿った黄色の円と半分の円を前面に描く (塗っている間・B で調整している間は doDrag の絵にだけ描く。マニピュレータの絵に描くと、押した所に円が残った)。囲む線のプレビューもドラッグ中に作り直す (`_update_loops`。重いメッシュでも軽いよう、前に作り終えてから max(0.05 秒, かかった時間 x 2) たつまでは作らない。離したときは必ず作る)。半径はワールドの
長さ (最初はメッシュの大きさの 3%)。B は押している間だけのキー (`keys.HOLD_KEYS` / `HELD`。ペイントのときだけ受け取り、
ほかは Maya に渡す)。塗った範囲の表示は、囲む線と同じ面 (`core/region.painted_triangles`) を同じ濃さで塗る (三角形ごとの量の平均を濃さにすると、三角形ごとに色が違い線とも合わなかった。GUI で確認)。塗った範囲の色が囲む線と重なって見にくかった (GUI で確認) ので、重ね塗りは線の色とぶつからない薄い青
(不透明度 0.25。設定「塗った範囲を表示」で出す。既定は出さない: 囲む線だけのほうが見やすかった)、塗っている間の囲む線と
編集で選んだペイントの線は前面 (X 線) に黄で描く (黒いふちを付けたらギザギザして見にくかった)。

**色の設定**: ツール設定のウィンドウの欄はモード・ガイドの種類ごと (モード / リング / フリーハンド・ライン / カーブ /
ペイント / 編集 / シーム)。線・塗った範囲・ブラシ・選んだ線・点の印・シームの色を、色の四角 (canvas) を押して色の選択 (colorEditor) で変えられる (colorSliderGrp はスライダーが長くウィンドウから見切れた)
(設定の種類 COLOR。値は (r, g, b)、optionVar に残る。フラグは `-ringColor "r g b"` など。コンテキストのコマンドは
文字列を返せないので、ウィンドウは `tool_ui.color_value` で読む)。
**ウィンドウの文字が「???」になった**: 説明に波ダッシュ「〜」(U+301C) を書くと、MEL ではその後ろの日本語がすべて「?」に
なる (SkinWeightSlider で確かめた落とし穴)。`tool_ui_text.mel_string` が「～」(U+FF5E) に置き換える。塗った面はガイドの
`faces` (面の番号のリスト) に保存するので塗り直せる (メッシュのトポロジーを変えると合わなくなる。前の版の `weights`
(頂点ごとの量) は、読むときに面の頂点の平均が 0.5 以上の面に直す `faces_from_vertex_weights`)。対称の相手は
塗った面を鏡に写して作る (`core/region.mirror_faces`: 面ごとに、自分の中心を鏡に写した所にいちばん近い面の値を拾う。
写った先の側から拾うので、左右で面の細かさが違っても穴が空かない)。中心をまたいで塗って相手が自分と重なるなら相手は作らない。
編集のモードでペイントを選ぶと塗った範囲が重ねて見える。点の印は出さない (線ではなく塗った範囲で直すため)。

**カーブ** (`core/curve.catmull_rom`・`scene/edit.add_curve`): 置いた点を通る centripetal Catmull-Rom
(点と点の「時間」を距離の平方根にする。点の間隔がばらついても行き過ぎ・小さな輪ができにくい)。開いた線の端は
端の点を鏡に写した点で延ばす。曲線は 3D で作ってから表面のいちばん近い点に寄せるので、途中でカメラを回しても
形は変わらない (ラインは画面の直線を、点を置いたときの視点で表面に落とす)。点は最初の点と同じメッシュの上だけ。
描いている間は表面に寄せない曲線を見せる (軽くするため)。置いた点がガイドの点になり、区間は曲線。色は薄紫。

**点の編集** (編集のモードで選んでいる線すべて。**ガイドの統一** (2026-10-20、[05_unified_spec.md](05_unified_spec.md))
で、どのガイドも点 + 区間の作り方 + 点の付き方を持ち、同じ操作で編集する。点の印はどのガイドもその点 (リングは断面の
等間隔の 4 点、フリーハンドは両端、ペイント・境界は形を間引いた点)):

区間は形を覚えておき、点を編集しても **変わった区間だけ** 作り直す (ラインの直線の区間は 3D の直線を細かく分けて表面に
寄せる = カメラによらない)。固定の区間 (手描き・断面・エッジ) は、その端の点を動かすと曲線に変わる。点を足すのは線の上の
いちばん近い点で、形は変えない。点を消すと前後の区間を 1 本の区間に作り直す (端の点なら端の区間を消す)。

| 操作 | 内容 |
|---|---|
| 点の印 | 黒いふちの付いた白い四角 (作成で描いている線の点も同じ)。選んだ点・動かしている点は黄色 |
| 点をドラッグ | 動かす (マウスの下の表面へ。ドラッグ中は前の線と相手を隠してプレビューだけ描き、離したときに 1 回の Undo で作り直す) |
| 点をクリック / Shift+クリック / Ctrl+Shift+クリック | 点を選ぶ (置き換え / 切り替え / 足す)。**いくつでも選べる** (選んでいる線が何本でも)。Esc で点の選択を外す |
| 矩形 | 矩形にかかるのが選んでいる線 (と相手) だけなら、入る点の印を選ぶ (修飾キーは Maya と同じ)。ほかの線にかかればガイドを選ぶ |
| 選んでいる点のどれかをドラッグ | 選んでいる点をまとめて、押したときの画面の位置から同じだけずらした所の表面へ動かす (何本の線でも 1 回の Undo)。選んでいない点を押したときはその点だけ |
| Delete / Backspace | 選んでいる点をまとめて消す (線ごとに、開いた線は 2 点・閉じた線は 3 点まで残す。1 回の Undo) |
| 点の Ctrl+クリック | その点を消す。ガイドそのものは Ctrl+クリックでは消さない (誤操作になるため。ユーザーの指定) |
| 端の点をクリックで選んでから、ガイドの無いメッシュの上のクリック | **端から伸ばす**。カーブは点を足し (伸ばした先が新しい端になり、続けてクリックで伸ばせる)、補助線は画面の直線をそのときの視点で表面に落とした区間を足す (作成のラインと同じ。途中でメッシュから外れる所へは伸ばさない)。対称の相手も合わせる。1 回ずつの Undo。ほかのガイドの上のクリックは、伸ばさずにそれを選ぶ。真ん中の点を選んでいるときは伸ばさない |
| 端をほかのガイドへドラッグ | 開いた線の端の点を、ほかのガイドの線の近くで離すとそのガイドに乗る (ひし形の印。そのガイドのシームの上をスライドし、土台が動けば付いて行く)。離れた所へドラッグすると外れる |
| 「区間: …」のボタン | 選んだ点の間の区間 (点を選んでいなければガイド全体) の作り方を 曲線 -> 直線 -> 最短 -> 谷 と順に替える (`segmentMode`) |
| 選んだ線の上のクリック (修飾キーなし。ガイドを 1 本だけ選んでいるとき) | その位置に点を足す (いちばん近い区間を形の点で分ける `scene/edit.insert_point`)。すでに選んでいる線のクリックは選択を変えないので、それを点の追加に使う。Shift+クリックは Maya と同じ選択の切り替え |

**つなぐ・切り離す** (編集のモード。ビューの下の段 (編集のモードのときだけ出る)・ツール設定のウィンドウの「つなぐ」「切り離す」):

| 操作 | 内容 |
|---|---|
| 線を 2 本選んで「つなぐ」 | 近い端どうしをつないで 1 本にする (カーブ・ライン・ペイントを混ぜられる)。つなぐ区間は、両側の区間がどちらも曲線なら曲線、そうでなければ 3D の直線 (端がほぼ同じ所なら区間を作らず点を 1 つにする)。対称の相手どうしもつなげる (中心をまたぐ 1 本になり、相手は作らない) |
| 線を 1 本選んで「つなぐ」 | 始点と終点をつないで閉じる (3 点以上) |
| 点を 1 つ選んで「切り離す」 | その点で 2 本に分ける (端の点では切れない)。閉じた線は、その点で開いた線にする |
| 点を 2 つ以上選んで「切り離す」 | 両端の点をどちらも選んでいる区間 (隣り合う 2 点の間) を消して分ける (`scene/edit.cut_segments`。閉じた線は開く。点が 1 つだけになった切れ端は捨てる)。隣り合う 2 点が無ければ何もしない |

つないだ線は、点と、区間ごとの作り方を持つ 1 本のガイド。曲線の区間は前後の点も使って Catmull-Rom で作り直し
(`core/curve.curve_segment`)、ほかの区間は覚えている形を残す (`scene/edit.py` の `move_points` / `insert_point` /
`delete_points` / `extend_path` / `join_guides` / `split_guide` / `cut_segments`。どのガイドもこれで編集する)。
どれも 1 回の Undo で、対称の相手は作り直す。
ビューのボタンは 3 段 (どれも中央。`core/panel.ROWS`): 上にモード (作成 / 編集) と対称、真ん中にガイドの種類 (1～5)、下に操作 (UV をカット・エッジを選択、編集のモードでは つなぐ・切り離す も。`EDIT_ONLY`)。1 段だと 1,000 px を、2 段 (上にモード・種類・対称) でも 800 px を超えて横に長かった (GUI で確認)。並びはコンテキストの `panelButtons()` がモードと状態から作り、マニピュレータは押したボタンもこの並びで引く。

どれも対称の相手を、新しい点を鏡に写して表面に寄せた点で作り直す (どちらを編集しても、もう片方が合わせて変わる。
`scene/edit._sync_partner`)。点の印は線より優先して拾う。
点の印は線だけの小さな四角で見にくかったので、黒いふち付きの塗った四角 (`drawing.draw_handles`) にした。
ドラッグ中に前の黄色の線が残った (GUI で確認): Maya はドラッグ中にマニピュレータを描き直さず、押す前の絵が残る
(テストでは見えない)。点を押したときに、編集する線 (と相手) と動かす点を外した絵に描き直させ (`_redraw`)、
プレビューと動かす点は doDrag の絵 (`_drag_drawing` の間) にだけ描く。

Ctrl+Z: 線を描いている間は Maya の Undo では描きかけの線が戻らなかったので、キーのフィルター (`keys.KEYS_CTRL`) で
受け取り、最後の点を戻す (描いていなければ受け取らず Maya に渡す)。

どの種類でも:

| 操作 | 内容 |
|---|---|
| ホイール | 選んでいる閉じたガイド (輪・閉じたライン・ペイントの線など) を、面の向き (輪は平面、ほかは主成分の面の法線) に平行移動 (1 目盛り = 点の間隔 x 2。Ctrl で 5 目盛りずつ)。カーソルが選んだガイド (か対称の相手) から 60 px 以内のときだけ。離れていればカメラのズーム |
| Shift+ホイール | 選んでいる閉じたガイドを、カメラの向きを軸に回す = 画面の上で線を回す (3 度。Ctrl+Shift で 15 度) |
| Delete / Backspace | 選んだガイドをまとめて消す (対称の相手も。1 回の Undo)。選んでいないときは Maya に渡す |

**選択のモード** (Maya と同じ選び方):

| 操作 | 内容 |
|---|---|
| クリック / ドラッグ (矩形) | 選ぶ (置き換え。何も無い所なら外す) |
| Shift / Ctrl / Ctrl+Shift + クリック・ドラッグ | 切り替え / 外す / 足す |
| ホイール・Shift+ホイール・Delete・Esc | ガイドのモードと同じ (最後に選んだ輪を動かす・まとめて消す) |
| Esc | 描いている線・折れ線をやめる / 選択を外す |
| Ctrl+Z | 足す・消すを 1 回ずつ戻す (Undo の名前「輪切りのガイド」「補助線のガイド」「ガイドを消す」) |

色: 輪切り = 水色、補助線 = 橙、選んだもの = 黄 (太い)、マウスの下 = 明るい黄。

## 輪の形を点で変える (2026-10-20)

輪切りのガイドに点を足して、カーブのように形を曲げる (ユーザーと決めた仕様)。**ガイドの統一 (段階 3・4) で、下の
仕組みはどのガイドとも同じ点の編集に置き換えた** ([05_unified_spec.md](05_unified_spec.md))。今の動き: 作った輪は
最初から断面の等間隔の 4 点を持ち、線のクリックで形を変えずに点を足す。点を動かすと、その前後の区間が曲線に変わる。
断面のままの輪のホイールは断面を求め直し、点を編集した輪は形ごと動かす。3 点未満に消すか「断面に戻す」で断面の 4 点に
戻る。輪も切り離せる (開いた線になる)。以下は統一の前の記録。

- **点を足す**: 編集のモードで輪を **1 本だけ**選び、線をクリック。点の無い輪 (断面) は、クリックした所と、そこから
  等間隔の支えの点 4 つの 5 点を置き (`scene/edit.insert_ring_point`。`RING_SUPPORTS`)、点を通る閉じた曲線
  (カーブと同じ centripetal Catmull-Rom を表面に寄せたもの) にする。形は元の断面にほぼ重なる。点を持つ輪は
  カーブと同じく線の上に足す。何本か選んでいるときの輪の線のクリックは選び直し (足すと思わぬ所で輪が曲線に
  変わるため)
- **点の編集**: カーブと同じ (ドラッグ・Shift / 矩形で複数・Ctrl+クリックや Delete で消す)。点を持つ輪は
  `_as_path` がパスとして扱い、区間はすべて曲線 (`path_flags`)、作り直しても種類は輪のまま (`_apply_path`)。
  点が 3 つ未満になる消し方は、断面の輪に戻す
- **ホイール**: 形を保ったまま動かす。点ごと、平面と同じだけ回して平行移動し、表面に寄せ直す
  (`adjust_ring` の点を持つ輪の分岐 -> `_move_ring_anchors`)。寄せた点が輪の大きさより離れたら動かさない
- **断面に戻す**: 操作「断面に戻す」(`ringReset`。編集のモード) で点を捨て、今の平面の断面の輪に戻す (`reset_rings`)
- 対称の相手も点を持ち、鏡の形になる。輪は切り離せない (`split_guide` / `cut_segments` は輪を断る)。輪に乗った
  つなぎ線は、点の編集にも付いて行く (土台の線が変わるので `follow_hosts`)
- ビューの操作の段が 7 つになったので、操作は 4 つずつで下へ折り返す (`core/panel.ACTIONS_PER_ROW`)

テスト: [test_ring_points.py](../../tests/SeamGuide/mayapy/test_ring_points.py)。

## 対称 (X)

UVPathCut と同じ仕様。設定 `symmetry` (既定オフ・`-sy`)・`mirrorSpace` (ワールド / オブジェクト。既定オブジェクト・`-ms`)・
`mirrorAxis` (X / Y / Z。既定 X・`-ma`)・`mirrorTolerance` (既定 0.1・`-mt`。設定の種類 FLOAT)。X キー・ビューの上の段の
ボタン (「対称 X」/「対称 OFF」/「Maya 対称 Z」。`core/actions.symmetry_label`・切り替えのボタン `TOGGLES`)・ツール設定の
ウィンドウの「対称」の欄で切り替える。

- オンなら、新しく描いたガイドに反対側の相手も作る (`scene/edit._add_partner` が `target.symmetric()` を見る)
- **Maya の対称がオン (ワールド / オブジェクト) の間は Maya の面と許容値**で、ツールの対称がオフでも両側に作る
  (`scene/mirror.mirror_state`。ウィンドウの空間・軸・許容値は灰色になり「Maya の対称: …」を出す。Maya の対称の
  変更には通知が無いので、ボタンの文字は 0.5 秒に 1 回まで読み直す `mayaSymmetry`)
- 前に作った相手との組は、対称をオフにしても残る (点の編集・切り離す・つなぐ・輪を動かす・塗り直しで相手も作り直す。
  `_add_partner(force=)`)。反対側は作ったときに決まる (UVPathCut と同じ)
- 許容値はペイントの塗った面を写すときに使う (`core/region.mirror_faces`: 鏡に写した位置から許容値の中に面の中心が
  あれば対応する面。無い所 (左右で形が違う所) もいちばん近い面で写し、その数をログに出す)
- スクリプトから `scene.edit` を使うとき (ツールの設定を付けない `GuideTarget`) は、前の版と同じくオン・オブジェクト X

## 仕組み

- **ガイドはアトリビュートが正**: 足す・消すはガイドの写しを変えてアトリビュートに書き (`undoInfo` の名前付きの
  チャンク)、ツールはアトリビュートの変更の通知で読み直して描く。Undo / Redo も同じ道を通るので、表示と
  シーンが食い違わない。ガイドはシーンといっしょに保存される
- **輪切り**: 押したときにビューの投影と視線の関数を作り、ドラッグのたびに `find_rings` (視線をオブジェクト
  空間に写して平面を作り、断面の線のうち描いた線の範囲のもの)。離したら点の間隔を揃え、対称の面で写して
  表面に寄せた相手といっしょに足す
- **補助線**: 画面の線を 4 px おきに取り、離したときに全部の視線を対象のメッシュすべてに当てて、点ごとに
  いちばん手前のメッシュを選ぶ
- **ドラッグ中の表示**: Maya はツールのドラッグ中にマニピュレータを描き直さないので、ガイドとプレビューを
  `doDrag` の drawMgr にも描く (UVPathCut の輪切りと同じ)。プレビューの対称の相手は、軽くするため表面に
  寄せずに鏡に写しただけ
- **形の変更**: シェイプの dirty (ガイドのアトリビュート以外) で、メッシュの配列・当てる仕組みを捨てる
  (次に使うときに作り直す)
- **テストのため**: マウスの処理は `press` / `drag` / `release`。`viewFunctions` に (投影, 視線) を入れると
  ビューの代わりに使う (standalone にはビューが無い)

## 描く手助け (追加)

直線で描きたいときにフリーハンドではぶれるため、3 つ足した (`core/stroke.py`):

- **折れ線** (`tool/context.py` の `Polyline`): 区間は画面の直線を `SAMPLE_PIXELS` おきの視線にして表面に当てる
  (`scene.edit.cast_rays`)。点を足すたびにその場で当て、**表面の点** を覚えるので、途中で視点を回しても前の
  区間はずれない (次の区間はそのときの視点で真っすぐ)。確定は `scene.edit.add_line_hits`。閉じた線は、
  最初の点に戻った最後の点を除いてから閉じた線として間隔を揃える (つなぎ目に長さ 0 の区間を残さない)。
  1 本の直線も「2 点で確定」でできるので、単発の直線モードは作らなかった (曲がりながら続くシームを少ない点で
  引けて、カットに使いやすい)
- **レイジーマウス** (`LazyBrush`): カーソルとペン先をひも (`LAZY_PIXELS` = 20 px) でつなぎ、カーソルがひもより
  離れたときだけ、ひもが張る分だけペン先が追う。手ぶれの小さな揺れはたるみに吸われる。線はペン先で終わる
  (離した位置ではない)。ドラッグ中はペン先からカーソルまでのひもを灰色で描く
- **ステップ** (`snap_angle`): 線の向きを画面で `STEP_DEGREES` (15 度) 刻みに丸める (長さはそのまま)。
  7.5 度より大きい傾きは次の刻みになる

ゴム紐 (最後の点からマウスまで) と点の印は画面の 2D で、マニピュレータの doMove (`hoverAt`) で描き直す。
キー: Enter = 確定、Backspace = 折れ線の間は点を戻す / それ以外は選んだガイドを消す。

## 輪の平行移動・回転 (追加)

UVPathCut の輪切りの「ずらす / 傾ける」と同じ操作。SeamGuide は離したらすぐガイドにするので、
**選んでいる輪をあとから動かす** 形にした (ドラッグで作った輪は選ばれた状態になり、そのままホイールで調整できる)。

- 輪切りのガイドは、作ったときの平面 (点・法線) と描いた線の向き (平面の中で視線に直交する向き = 傾ける軸) を
  オブジェクト空間で持つ (`Guide.plane` / `Guide.axis`。JSON の `plane` / `axis`。対称の相手は鏡に写したもの)
- `scene.edit.adjust_ring`: 輪の中心を平面に乗せて回転の中心にし、法線を軸のまわりに回す (`rotate`) / 法線の向きに
  ずらしてから断面を求め直し、**今の輪の中心にいちばん近い** 線を選ぶ (中心どうしが輪の大きさより離れていたら
  メッシュから外れたとして動かさない)。対称の相手は作り直す (中心を通るようになれば消え、外れれば作る)
- 1 目盛りごとに書くと Undo が目盛りの数だけ積まれるので、動かした結果は写しを表示しておき、ホイールを止めて
  `COMMIT_MS` (0.5 秒) たったら 1 回の Undo (「輪切りを動かす」) で書く。ほかの操作 (押す・キー・ツールを抜ける)
  の前にも書く。書く前にほかの変更 (Ctrl+Z など) の通知が来たら、動かした分は捨てる (古い写しで上書きしない)
- **回す軸はカメラの向き** (ユーザーの要望): Shift+ホイールは、カメラから輪の中心への視線を軸に回す (画面の上で
  描いた線が回る)。最初は描いた線の向きを軸に手前 / 奥へ傾けていたが、同じことは横から見て回せばできる。
  `adjust_ring(rotate_axis=)` に視線をオブジェクト空間で渡し、記録の軸 (axis) も一緒に回す。中心を通る輪を
  画面で斜めにすると左右対称でなくなるので、対称の相手ができる (戻すと消える)
- ホイールは Qt のフィルターで受け取り、輪を選んでいないときは Maya に渡す (カメラのズーム)。Shift+ホイールを
  横の回転にする環境があるので、縦が 0 なら横の量を使う
- 平面を持たない前の版の輪は動かせない (描き直す)

## モード (追加)

選択の足す / 切り替え / 外すを Maya と同じキーにしたいため (ユーザーの要望)、描く操作と選ぶ操作をモードに分けた
(UVPathCut のパス / 選択と同じ考え方)。

- 設定は `core/settings.py` の定義表 (今は `mode` だけ)。`Settings` は変えたらリスナーへ知らせ、
  optionVar `seamGuideSettings` に既定と違う値だけ保存する (`scene/prefs.py`)。コマンドのフラグ
  (`seamGuideCtx -e/-q -mode`。問い合わせは番号) とツール設定のウィンドウ (`core/tool_ui_text.py` ->
  `tool/tool_ui.py`。欄ごとの frameLayout。将来ガイドの一覧の欄を足す) を表から作る
- ビューのボタン: `core/panel.py` が並び (下の中央に「ガイド」「選択」)、マニピュレータが押せる部品
  (kSelectable。`ScreenPlane` で画面の四角をカメラの前の平面に戻して 3D で描く) として描く。今のモードは
  active の色。押して、同じボタンの上で離したらそのモード。ボタンの上ではガイドのホバーをしない
- 選択のモードの押下は、クリックならマウスの下のガイド、ドラッグなら矩形 (`guides_in_rect`) を、
  離したときの修飾キー (今の状態。読めなければ押したとき) で `applySelection` に渡す
  (置き換え / Shift 切り替え / Ctrl 外す / Ctrl+Shift 足す)。Shift+クリックでも折れ線は始めない
- モードを替えたら、折れ線・描いている線をやめ、動かした輪を書き、ヘルプの文字とウィンドウを合わせる
- ガイドのモードの Ctrl+クリック (足す / 外す) と Ctrl+Shift+ドラッグ (矩形) は、選択のモードに移したので外した

## 落とし穴

- **ホイールは輪の近くでだけ**: 輪を選んでいるとビューのホイール (ズーム) がすべて輪の移動になり、使いにくかった
  (GUI で確認)。カーソル (マニピュレータの doMove で覚える `cursor`) が選んだ輪か相手から `WHEEL_PIXELS` (60 px)
  以内のときだけ動かす。動かし始めたら、書くまで (止めて 0.5 秒) は離れても続ける (輪が動いてカーソルから離れ、
  途中でズームに替わらないように)

- **ツールに入ったら対象をエッジの選択モードにする** (`scene.targets.enter_edge_mode`。UVPathCut と同じ。Undo に
  積まない): オブジェクトを選んだままだと、ワイヤーフレームが選択の緑で描かれ、ガイドやシームが見にくかった

- **ツール設定のウィンドウの値は python() で読む**: `seamGuideSetValues` で `seamGuideCtx -q -seamPreview` が空を返し、
  `checkBoxGrp -value1` が「Invalid argument:」になった (GUI。standalone ではコンテキストを作れず原因は未確認)。
  値は `tool/tool_ui.setting_value` (保存した設定 = optionVar。変えるたびに保存するのでツールの値と同じ) から
  `python("...")` で読む (UVPathCut の色と同じ方法)。MEL では「python(...) + 1;」だけの文は構文エラーになるので、
  テストは値を返すプロシージャにして式として評価する

- **Esc は Qt のキーで受け取る**: Maya は Esc でコンテキストの `abortAction` を呼ぶが、GUI ではドラッグ中・
  折れ線の途中で効かなかった。Delete と同じ Qt のフィルター (`tool/keys.py`) で受け取り、描いているもの・
  折れ線・選択があるときだけ使う (無ければ Maya に渡す)。`abortAction` も残してある
- **Ctrl は今の状態を読む**: 押したときの `MEvent` の修飾キーだけでは、ドラッグを始めてから押した Ctrl が
  分からず、15 度刻みが効かなかった。ドラッグ中・離したときに `QApplication.queryKeyboardModifiers`
  (`keys.modifiers`) で読む。途中で押しても離しても効く

- テストの投影は画面の **ピクセル** に合わせる (ドラッグとクリックの境・拾う距離は px。ワールドの 1 を 1 px に
  すると、ドラッグがクリックになり、遠くのガイドまで拾った)
- `MPxContext` (選択のコンテキストではない) を使う。左ボタンで Maya の選択は変わらない
