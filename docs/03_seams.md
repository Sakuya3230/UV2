# 3. ガイド -> エッジ (シーム) -> UV のカット

[目次](README.md) ・ 前: [2. ガイドを描くツール](02_tool.md)

## 目的

描いたガイド (エッジに関係ない表面の上の線) を、メッシュのエッジの道 (シーム) にして見せ、そのエッジで UV を
カットする。デシメートした不規則な三角形のメッシュでも、ガイドの近くのエッジを選んで沿わせる。

## 使い方

ガイドを描くと、ガイドから求めたエッジが **赤紫** で描かれる (設定「シームを表示」。ツール設定のウィンドウの
「シーム」の欄)。ビューの下のボタン (ガイド / 選択 の右) とウィンドウのボタン:

| ボタン | 内容 |
|---|---|
| UV をカット | シームのエッジで UV を切る (`polyMapCut`。全メッシュで 1 回の Undo「シームで UV をカット」) |
| エッジを選択 | シームのエッジを Maya で選ぶ (エッジの選択モードにする。ほかのツールで使う・確かめる) |

スクリプトから: `cmds.seamGuideCtx("seamGuideContext", e=True, runAction="cut")`。

## 仕組み

1. **中継点**: ガイドを細かく (エッジの長さの中央値 h の半分の間隔で) 置き直し、`WAYPOINT_EDGES` (6) x h ごとに
   中継点を置いて、いちばん近い頂点を選ぶ (scipy の `cKDTree`。無ければ総当たり)
2. **区間ごとの最短パス**: 隣り合う中継点の間を Dijkstra でつなぐ。重みは
   `エッジの長さ x (1 + OFF_WEIGHT x (ガイドからの距離 / h)^2)` (`OFF_WEIGHT` = 4)。距離は両端の頂点の、その
   区間のガイドの線までの距離の平均。探すのは区間のガイドから `BAND_EDGES` (4) x h 以内の帯だけで、着けなければ
   帯を 2 倍にしてやり直す。閉じたガイドは最後の中継点から最初へ戻る
3. **つなぎ直し**: 区間の道をつなぎ、行って戻るとげと、同じ頂点を 2 回通る小さな輪を取り除く
4. 道は **面の辺だけ** でたどる (`MeshArrays.adjacency`)。断面の計算で使う三角形の対角線は本物のエッジではないため
5. **覚えておく**: `SeamBook` はガイドの種類・閉じているか・点の列を鍵に道を覚える (メッシュの配列が作り直されたら
   捨てる)。ホイールで輪を動かすと、その輪の分だけ求め直す。Maya のエッジの番号は、道の頂点につながるエッジ
   (`MItMeshVertex.getConnectedEdges`) から相手の頂点が合うものを探す (全エッジを読まない)
6. **カット**: エッジの名前は続いた番号を `e[a:b]` にまとめ、`polyMapCut` を名前付きの undoInfo のチャンクで呼ぶ

対称: 対称の相手のガイドも 1 本のガイドとして同じように求める (左右で頂点が揃っていれば、同じ形のシームになる)。

## 落とし穴

- 1 回目は重い: 頂点の木・面の辺 (np.unique)・隣接の表を作る分 (30 万頂点で 1.7 秒)。メッシュごとに 1 回なので、
  ツールに入ったら手すきのとき (`executeDeferred`) に作っておく。2 回目からは 30 万頂点でも 1 本 0.1 秒ほど
- シームはいちばん近いエッジに乗るので、輪を少し動かしても (エッジの間隔の半分まで) 同じエッジのまま
  (テストで最初に「動くはず」と書いて外れた)
- 輪の面の法線の向きは描いた線の向きで決まるので、ホイールの上下と移動の向きは輪によって逆になる
- UV を編集するだけでもメッシュの dirty が来て配列を作り直す (次に描くときに 1 回目と同じ重さ)。重く感じたら、
  頂点の位置・数が同じなら作り直さない形にする

## 実測

| | |
|---|---|
| 頂点 30 万の三角形の球の斜めの輪 (628 頂点の道) | 1 回目 1.7 秒 (用意込み) / 2 回目から 0.11 秒 |
| デシメートした球の輪 | 9〜14 ms |
| サンプル (人の体) の両腕の輪 2 本 | 17〜24 ms。カットで UV のシェルが 44 -> 46 |

## 試し方

```
"C:\Program Files\Autodesk\Maya2027\bin\mayapy.exe" scripts\tests\SeamGuide\mayapy\test_seams.py
```

GUI: サンプルを読み込み、`SeamGuide.tool()`。腕を輪切りすると水色のガイドに沿って赤紫のシームが出る。
ホイールで輪を動かすとシームもエッジの行ごとに動く。3 (ライン) のクリックの折れ線で胴の脇をなぞり、「UV をカット」
-> UV エディタでシェルが分かれている。Ctrl+Z 1 回で戻る。「エッジを選択」でシームのエッジが選ばれる。
