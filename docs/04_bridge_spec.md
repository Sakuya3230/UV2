> ガイドになり、点の編集はほかのガイドと同じ関数 (`move_points` / `insert_point` / `delete_points`) で行う。下の表の
> `BridgeEnd`・`ends` / `stops`・`line_path`・`build_bridge`・`resolve_end`・`*_bridge_*` の関数は統一の前の記録で、

## 目的

手足・尻尾などを切り開く切れ目を、**2 本のガイドの間をエッジの最短パスでつなぐ線**として作り、端点と中継点で
形を直せるようにする。例: 腕の付け根の輪と手首の輪の間を、腕の裏側でつなぐ。

すでにカットした境界 (UV の切れ目) や手で選んだエッジもつなぐ土台にできるよう、**エッジをガイドに変換**する。

## ガイドの種類 (2 つ足す)

| 種類 | 保存するもの | 線 (= シーム) |
|---|---|---|
| **つなぎ線** (BRIDGE) | 両端 (乗っているガイドの ID と、そのシームの上の位置) と、中継点 (頂点の番号) の列 | 端点 -> 中継点 -> … -> 端点 を、エッジの最短パス (長さの重み。面の辺だけ) でつないだ頂点の列。点はちょうど頂点の上なので、シームはその頂点の列をそのまま使う (`core/edge_path.vertex_path`。ペイントと同じ) |
| **境界** (EDGE) | 頂点の番号の列 (閉じているか) | その頂点の列そのもの |

## 端点

- 端点は **乗っているガイドのシーム (エッジの道) の頂点の上**にある。保存するのは (ガイドの ID, シームの上の位置 =
  長さの割合 0〜1)。乗っているガイドの線 (輪など) は頂点の上を通らないので、線の上に置くとシームが途中で
  途切れることがある。シームの頂点に乗せれば、カットが必ずつながる
- 乗っているガイドが変わる (ホイールで動かす・点の編集・塗り直し) と、端点は**前の端点の位置にいちばん近い、
  新しいシームの頂点**に付いて行き (割合はそのあと付け直す)、つなぎ線を作り直す。はじめは「同じ割合の位置」に
  していたが、輪を作り直すたびに一周の数え始めが変わり、端点が輪の上で大きく回った (GUI で確認。不規則な
  円柱で最大 178 度。`case_follow_irregular`)
- 乗っているガイドを消したら、端点は **消える前の頂点に固定**され、つなぎ線は残る (その端点は中継点と同じく
  表面の上を自由に動かせる)
- 乗れるガイド: シームのあるガイドすべて (リング・フリーハンド・ライン・カーブ・ペイントの囲む線・境界)。
  つなぎ線の上には乗れない (つなぎ線どうしの依存の輪を作らない)。同じガイドの 2 点をつないでもよい

## 作り方

**作成のモードの種類「6 つなぎ線」** (「6 裏側」と入れ替え):
1. ガイド A の上をクリック -> そこに最も近い、A のシームの頂点が端点になる (ガイドに当たっていないクリックは無視)
2. (任意) ガイドの無いメッシュの上をクリック -> 中継点 (近い頂点)。プレビューの線が付いて来る
3. ガイド B の上をクリック -> 端点を置いて確定 (対称の相手も。1 回の Undo)
4. Backspace・Ctrl+Z = 最後の点を戻す、Esc = やめる (ラインと同じ)

**編集のモードで 2 本選んで「つなぎ線」ボタン**でも作れる (端点は自動): それぞれのガイドのシームのうち、今の
カメラから見て**奥側**の頂点 (A はいちばん奥の頂点、B は奥側の半分の頂点のうち、A の端点から最短パスがいちばん
短いもの)。手足を裏側で切り開くのに向く (裏側の意図を残す)。

## 編集 (カーブと同じ操作)

つなぎ線を選ぶと点の印 (端点は形を変えて区別):
- **端点のドラッグ**: 乗っているガイドのシームの上をスライドする (外れない)。画面のマウスの位置に、シームの
  頂点のうち画面でいちばん近いもの
- **中継点のドラッグ**: 表面の上を動き、近い頂点に吸い付く
- **パスのクリック**: そこに中継点を足す (クリックした所に最も近いパスの頂点。前後の区間の間に入る)
- **Ctrl+クリック / Delete**: 中継点を消す (端点は消せない)
- Shift / 矩形で複数の点を選び、まとめて動かす・消す (端点はそれぞれ自分のガイドの上をスライド)
- どれも 1 回の Undo。対称の相手も作り直す

## 境界をガイドにする (変換)

ボタン「境界をガイドに」(ビューの操作の段とツール設定のウィンドウ。作成・編集の両方):
- Maya で **エッジを選んでいれば、そのエッジ**。選んでいなければ **今の UV の境界 (カット済みの切れ目) すべて**
- つながりごとに境界のガイドにする。**枝分かれする頂点 (3 本以上の境界のエッジが集まる所) で区切り**、輪になって
  いれば閉じた線にする。メッシュの開いた縁は UV の境界でも対象にしない
- 境界のガイドは点を動かせない (消すことはできる)。対称の相手は自動では作らない
- 変換は 1 回の Undo

## 対称

- 今の対称の設定に従う (Maya の対称が優先、ツールの対称、前に作った組は残す。リングなどと同じ)
- 相手のつなぎ線の端点は、乗っているガイドの相手 (無ければ同じガイド。中心の輪など) のシームの上の、鏡に写した
  位置に最も近い頂点。中継点は、鏡に写した位置に最も近い頂点

## GUI で見つかったこと (段階 5 のあと)

1. **ホイールで輪を動かしても付いて行かない**: ツールはホイールの間 `target.guides` を書く前の写しに差し替えるので、
   それと比べると土台の変化を見落とした。比べる相手をシームに保存したガイドにした (`follow_hosts`)。ホイールの間も
   呼んでプレビューで付いて行く (`case_tool_wheel_follow`)
2. **端点が輪の上で大きく回る**: 「シームの上の同じ割合」で追うと、輪を作り直すたびに一周の数え始めが変わる。前の
   端点に近い頂点で追うようにし (`case_follow_irregular`。不規則な円柱で最大 178 度 -> 2 度)、さらに端点が
   **乗っているガイドの線の上の目印 (`BridgeEnd.point`。`ends` の 5 番目)** を覚え、新しい線の上のいちばん近い点へ
   移してから、そこに近いシームの頂点にした (傾けた輪のシームはジグザグの帯になり、前の頂点が帯に残ると止まるため)
3. **Shift で傾けると付いて行かなくなる**: 輪を動かす・傾けるたびに、輪の対称の相手を消して**新しい番号**で作り直して
   いた。相手のつなぎ線は相手の輪に乗っているので、土台が消えたことになって端点が固定され、そのあと付いて行かなく
   なった。相手を作り直すときは前の番号を使う (`_add_partner(reuse=)`・`GuideSet.renumber`。輪を動かす・切り離す・
   つなぐ・区間を消すのすべて。`case_partner_host_follow`)

## 通り方「谷」(2026-10-20 に追加)

つなぎ線が、2 点の間を**メッシュのくぼみ (筋肉の境・体の折れ目・甲殻の板の継ぎ目) を選んで**通る。少し遠回りでも
溝の底を通るので、継ぎ目が溝に隠れて目立ちにくい。別のガイドの種類にはせず、つなぎ線の通り方として選ぶ
(ユーザーと決めた)。

- 通り方はつなぎ線ごと (`Guide.route` = "shortest" / "valley"。JSON の `route`。無ければ最短)。新しいつなぎ線は
  設定 `bridgeRoute` (既定は最短) で、ビューの上の段 (対称の隣) の「通り方 最短 / 谷」ボタンで切り替える。編集で
  つなぎ線を選んでいれば、そのつなぎ線 (と相手) の通り方も切り替えて作り直す (`set_bridge_route`。1 回の Undo)
- 谷の強さ `valleyStrength` (既定 3。0 で最短と同じ)。つなぎ線を作る・作り直すときに使う (設定を変えただけでは、
  できているつなぎ線は作り直さない)
- くぼみの測り方 ([core/valley.py](../core/valley.py)): エッジを共有する 2 つの面の法線のなす角 (相手の面の中心が
  表側なら谷で正、裏側なら山で負) -> 頂点ごとに長さの重みで平均 -> 4 回ならす (スカルプトのノイズ・デシメートの
  ガタつきに引っ張られないように) -> 90 パーセンタイルで割って -1〜1。四角形の対角線は使わない (面の情報があれば
  多角形の法線)
- 道の重み = エッジの長さ x (1 + 強さ x (1 - くぼみ))。両端の頂点のくぼみの平均で、谷は長さそのまま、平らは
  1 + 強さ 倍、山は 1 + 2 x 強さ 倍。`core/bridge.shortest_vertex_path(weights=)` に渡す (scipy の疎行列は重みごとに
  覚える)
- 速さ: 20 万面で、くぼみが 0.2 秒 (最初の 1 回。ツールに入った直後の手すきのときに作る)、重みが 0.01 秒。最短パス
  1 回は最短と同じく 0.3 秒ほど
- 平らな所・なめらかな所では最短とほぼ同じ。くぼみを自動で探す機能ではない (始点・終点は作り手が決める)

テスト: [test_valley.py](../../tests/SeamGuide/mayapy/test_valley.py) (曲がった溝と盛り上がりのある平面: くぼみの値・
谷は溝に沿い最短は外れる・強さ 0 は最短・scipy の有無・保存・切り替えと Undo・ボタン)。
