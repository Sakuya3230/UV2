# ガイドの統一 (仕様と進み具合)

2026-10-20 にユーザーと決めた仕様。ガイドの種類ごとに編集の操作がばらばらだった (リングはホイール、つなぎ線は
端点のスライド、ペイントは塗り直し、フリーハンド・境界はほぼ動かせない…) ので、**どのガイドも同じ持ち方・同じ操作**
にする。作る道具 (1 リング〜6 つなぎ線・境界をガイドに) は、最初の形を作るだけになる。

## 決めたこと (ユーザーの選択)

| 問い | 決めたこと |
|---|---|
| 方向 | ガイド = 点 + 区間の作り方 + 点の付き方。作る道具は最初の形だけ。段階に分けて作り直す |
| 固定の区間 (フリーハンドの手描き・ペイント / 境界のエッジ・断面) の点を動かしたら | その点の前後の区間だけ曲線に変わる (動かさない区間は元の形のまま) |
| 作った道具に戻る操作 | 残す: リングは「断面に戻す」、ペイントは「塗り直す」(点の編集を捨てて作り直す) |
| ホイール (形ごと平行移動・傾ける) | 閉じたガイドすべて (開いた線では今までどおりカメラのズーム) |
| ペイントで確定したときの形 | エッジのまま (今と同じく塗った面の境目のエッジ = 見えた線がシーム)。点は形に合わせて間引いた数個、区間は固定。動かした所・「曲線」に切り替えた所だけなめらかになる (頂点ごとに点を置く案は、点が多すぎるので採らない) |
| つなぎ線 | 今までどおり、端点は乗っているガイドに付いて行く (動かす・点の編集・塗り直しで付いて行き、消えればその場に固定)。統一で、この「ガイドに乗る」点をほかのガイドの端にも使えるようになる |

## ガイドの持ち方

どのガイドも次の 3 つでできている。

1. **点 (制御点)**: 表面の上の点の列と、開いているか閉じているか
2. **区間の作り方** (点と点の間ごと):

   | 作り方 | 形 | シーム |
   |---|---|---|
   | 曲線 | 前後の点も使う centripetal Catmull-Rom を表面に寄せる (今のカーブ) | 線から重み付きの最短パス |
   | 直線 | 3D の直線を表面に寄せる (今のライン) | 線から重み付きの最短パス |
   | 最短 | エッジの最短パス (今のつなぎ線) | 頂点の列そのもの |
   | 谷 | くぼみを通るエッジの道 (今の通り方「谷」) | 頂点の列そのもの |
   | 固定 | 作ったときの形のまま (フリーハンドの手描き・断面・ペイントや境界のエッジ) | 形がエッジの上ならその頂点の列、そうでなければ最短パス |

   最短・谷の区間の両端の点は頂点に吸い付く。
3. **点の付き方** (点ごと): **自由** (表面の上を動く) か **ガイドに乗る** (別のガイドのシームの上をスライドする。
   今のつなぎ線の端点。乗っているガイドが動けば付いて行き、消えればその場に固定)

ほかに、作った道具に戻るための**元の情報**を持つ: リングは平面と軸、ペイントは塗った面。作った道具 (`origin`) は
表示の色と、戻る操作に使う。

## 作る道具がつくるもの

| 道具 | 点 | 区間 |
|---|---|---|
| 1 リング | 断面の輪の上の等間隔の 4 点 (閉じた線) | 固定 (断面の形そのもの) |
| 2 フリーハンド | 両端の 2 点 | 固定 (手描きの形) |
| 3 ライン | 置いた点 | 直線 |
| 4 カーブ | 置いた点 | 曲線 |
| 5 ペイント | 囲む線の形を間引いた点 (曲がりの大きい所に残す。囲む線ごとに 1 本のガイド) | 固定 (塗った面の境目のエッジ) |
| 6 つなぎ線 | 端点 (ガイドに乗る)・中継点 | 最短 / 谷 (上の段の「通り方」) |
| 境界をガイドに | 端と、形を間引いた点 | 固定 (エッジそのもの) |

## 編集の操作 (どのガイドでも同じ)

- **点**: 選んだガイドの点の印が出る。ドラッグで動かす (自由な点は表面の上、ガイドに乗った点はそのシームの上、
  最短・谷の区間の端は頂点に吸い付く)、線のクリックで足す、Ctrl+クリック / Delete で消す、Shift / 矩形で複数選ぶ
  - 固定の区間は、その端の点を動かすと曲線に変わる
- **端から伸ばす・つなぐ・切り離す**: どのガイドでも (閉じた線を切り離すと開いた線になる)
- **区間の作り方を変える**: 選んだ点の間の区間 (点を選んでいなければガイド全体) を 曲線 / 直線 / 最短 / 谷 に
  切り替える (操作のボタン)
- **端をガイドに乗せる / 外す**: 開いた線の端の点を、ほかのガイドの線の近くへドラッグすると吸い付いて乗る。離れた所へ
  ドラッグすると外れる
- **ホイール**: 閉じたガイドを形ごと平行移動・Shift で傾ける。向きは、リングは平面、ほかは線の平均の面 (主成分) の
  法線。点を一緒に動かして表面に寄せ直す。まだ点を動かしていないリングは、平面を動かして断面を求め直す (今までどおり
  正確な断面)
- **作った道具に戻る**: リングは「断面に戻す」(今の平面の断面)、ペイントは「塗り直す」(5 で塗り直して確定すると、
  点の編集を捨てて囲む線から作り直す)
- **対称の相手**: どのガイドも同じ仕組み (点を鏡に写して表面に寄せ、区間の作り方と点の付き方を写す。乗っている
  ガイドは相手のガイドへ)

## 保存とこれまでのガイド

- シェイプのアトリビュート `seamGuides` の JSON の版を上げる (version 2)。ガイドごとに `points` (点の位置と付き方)・
  `segments` (作り方と、固定・最短・谷の形)・`closed`・`origin`・元の情報 (`plane` / `axis`・`faces`)
- 前の版 (version 1) は読むときに新しい形に直す (リング・ペイント・境界は 4 点 + 固定、フリーハンドは両端 + 固定、
  ライン / カーブは置いた点 + 直線 / 曲線、つなぎ線は端点 (乗る) + 中継点 + 最短 / 谷)。書くときは新しい形

## 進め方 (予定)

1. 持ち方 (core): 点・区間・付き方のデータ、線の組み立て、保存 (version 2)、前の版からの変換。今のガイドがすべて
   同じ形で読めることを確かめる
   — **済み** (下の「段階 1 の実装」)
2. シーム: 区間ごとに求めてつなぐ (エッジの上の区間は頂点の列そのもの)
   — **済み** (下の「段階 2 の実装」)
3. 作る道具を新しい持ち方で (リング・フリーハンド・ライン・カーブ・ペイント・つなぎ線・境界)
4. 編集の統一: 点の印・動かす (固定 -> 曲線)・足す・消す・伸ばす・つなぐ・切り離す・区間の作り方・端を乗せる / 外す
   — 3・4 は**まとめて切り替えた** (下の「段階 3・4 の実装」。ツールもシーンの保存も新しい持ち方)
5. ホイール (閉じたガイドすべて)・断面に戻す・塗り直す
   — 切り替えと一緒に作った (`adjust_ring` / `reset_rings` / `set_region`)。GUI での確認が残り
6. 対称の相手・乗っているガイドへの追従を新しい持ち方で。古い特有のコードの整理、説明・テスト
   — 切り替えと一緒に作った (`_sync_partner` / `follow_hosts`。前の `BridgeEnd`・`line_path` などは消した)

## 点の間引き (ペイント・境界)

エッジの上の線 (頂点の列) を、少ない点で形を保つように間引く: 線から最も離れた頂点を残して分ける
(Douglas-Peucker。許容値は点の間隔の何倍か)。閉じた線は、互いにいちばん離れた 2 頂点から始める。点が少なすぎる
(閉じた線で 4 点未満) ときは等間隔で足す。4 点固定だと、凹んだ形を「曲線」に切り替えたときになぞれないため。

間引き)。

## 段階 2 の実装 (シーム)

[core/path_model.py](../core/path_model.py) の `path_seam(mesh, path)` (EdgePath か None) と `segment_seam` / `node_vertex`。

- 区間ごと: 頂点の列を持つ区間 (最短・谷・エッジの上の固定) はそれそのもの (本物のエッジでつながっているか
  `index_path` で確かめる)。表面の上の区間 (曲線・直線・手描きや断面の固定) は、区間の形に沿う重み付きの最短パス
  (`guide_edges`。前の版と同じ求め方)
- 区間の道の端が点の頂点 (`node_vertex`: 頂点を持っていればそれ、無ければ位置にいちばん近い頂点) からずれたら、
  最短パスで足して埋める。区間どうしは点の頂点でつながる
- つないだ道から、行って戻るとげと同じ頂点を 2 回通る輪を取り除く (前の版と同じ `_simplify`)。このため、表面の上の
  線のつなぎ目の点の頂点は、区間の道がそこで x -> 点 -> x と行って戻る所では通らないことがある (道はつながっている)。
  開いた線の両端と、エッジの上の線の点は必ず通る

前の版との比べ方 (`case_seams`): エッジの上の線 (ペイント・境界・つなぎ線) はエッジの集まりが同じ。表面の上の線は、
本物のエッジだけでつながり、線からの離れ方は前の版の 1.5 倍以内、前の版のエッジの 6 割以上を通る (区間ごとに
求めるので完全には一致しない)。区間を「最短」に作り直した線は、シームがその頂点の列そのもの。

ツールのシーム (`scene/seams.SeamBook`) も段階 3・4 でこれに切り替えた (前の `line_path` は消した)。

## 段階 3・4 の実装 (ツールの切り替え)

作る道具と編集を、まとめて新しい持ち方に切り替えた (途中で片方だけだと、編集が壊れるため)。

**ガイド** ([core/guides.py](../core/guides.py)): `Guide(path, ident, partner)` は線 (`GuidePath`) を 1 本持つだけ。
種類 (`kind`) は作った道具 (`origin`) から決まり (リング = RING、フリーハンド・ライン = LINE、カーブ = CURVE、
ペイント = REGION、境界 = EDGE、つなぎ線 = BRIDGE)、表示の色と戻る操作 (断面に戻す・塗り直す) にだけ使う。
`points` / `anchors` (点の位置) / `vertices` / `plane` / `axis` / `faces` / `group` / `pristine` は線から引く読み取り
専用の値。保存は version 2。前の版 (version 1) は `scene/store.read_guides` がメッシュを渡して直して読む
(`GuideSet.fromJson(text, mesh, spacing)`。前の版のクラスは `LegacyGuide` / `LegacyGuideSet` として変換にだけ残す)。

**作る道具** ([scene/edit.py](../scene/edit.py)):

| 道具 | 関数 | 作る線 |
|---|---|---|
| 1 リング | `add_rings` -> `_ring_path` | 断面の等間隔の 4 点 + 固定。source に plane / axis。pristine |
| 2 フリーハンド | `add_line_hits` | 両端の 2 点 + 固定 (閉じた線は間引いた点) |
| 3 ライン | `add_line_hits(anchors=)` -> `_line_path` | 置いた点 + 直線 (描いた形を区間の形に) |
| 4 カーブ | `add_curve` | 置いた点 + 曲線 |
| 5 ペイント | `add_region` / `set_region` (塗り直し) | 囲む線ごとに 1 本 (間引いた点 + 固定・頂点の列)。source に faces と group (同じ塗りの組。相手の側も同じ group) |
| 6 つなぎ線 | `add_bridge` | 端点 (ガイドに乗る `Node`) + 中継点 (頂点) + 最短 / 谷 |
| 境界をガイドに | `add_edge_guides` | 間引いた点 + 固定 (エッジの頂点の列) |

**編集** (どのガイドでも同じ関数):

| 操作 | 関数 |
|---|---|
| 点を動かす (ドラッグ) | `moved_path` (プレビュー) / `move_points`。動かした点の前後の固定の区間は曲線に。最短・谷の区間の端の点は頂点に吸い付く。ガイドに乗る点はそのシームの上をスライド |
| 端をガイドに乗せる / 外す | ドラッグで端をほかのガイドの線の近く (`PICK_PIXELS`) へ -> 乗る、3 倍より離す -> 外れる (`move_points(attach=)`・`set_end_attach`)。乗っている点はひし形の印 |
| 点を足す | `insert_point`: 線のクリック (ガイドを 1 本だけ選んでいるとき)。いちばん近い区間を形の点で 2 つに分ける (形は変わらない) |
| 点を消す | `delete_points`: 前後の区間をつなぐ (`_merge`: 両方固定なら固定、同じエッジの道なら同じ作り方、ほかは曲線)。断面の輪が 3 点未満になるなら断面に戻す |
| 区間の作り方 | 操作のボタン「区間: …」(`segmentMode`): 選んだ点の間 (無ければ全体) を 曲線 -> 直線 -> 最短 -> 谷 と順に (`set_segment_modes`) |
| 伸ばす・つなぐ・切り離す | `extend_path` / `join_guides` / `split_guide` / `cut_segments`。どのガイドでも (閉じた輪を切り離すと開いた線になる) |
| ホイール | `adjust_ring`: 閉じたガイドすべて (`Guide.adjustable`)。断面のままの輪は平面を動かして断面を求め直し、ほかは形ごと (`_transform_path`。向きは平面か主成分の面の法線) |
| 断面に戻す・塗り直す | `reset_rings` / `set_region` (番号と相手の番号は保つ) |

**対称の相手** (`_sync_partner` / `_mirror_path`): 点・形を鏡に写して表面に寄せ、区間の作り方と点の付き方を写す
(乗っているガイドは相手のガイド、無ければ同じガイド)。断面のままの輪は鏡に写した平面の断面。ペイントは塗った面を
写す。作り直しても相手の番号は前と同じ (`GuideSet.renumber`。つなぎ線の土台が消えたことにならないように)。

**乗っている点の付いて行き方** (`follow_hosts` / `_resolve_attach`。`_commit` が書く前に呼ぶ): 土台のガイドの線が
変わったら、点の目印を新しい線の上へ移し、そこにいちばん近いシームの頂点に置く。目印の移し方は 2 通り:

- 土台の点を動かした・形ごと動かした (点の数が同じで、断面のままの輪でない): **同じ区間の同じ割合の所**
  (`Attach.place` = (区間の番号, 区間の長さの割合, 点の数)、`path_model.segment_place` / `place_point`)。
  いちばん近い点で追うと、点を尖らせて曲げたときに端が曲げた所の脇へ滑った (輪の点の近くに乗ったつなぎ線のテストで再現)
- 断面のままの輪 (ホイールで断面を作り直すと点も作り直される)・点の数が変わった: 前の目印に**いちばん近い線の上の点**
  (前と同じ。割合で追うと一周の数え始めが変わって大きく回ったため)。点を足した・消した (形は同じ) ときは、place だけを
  今の線で取り直す

**ツール** ([tool/context.py](../tool/context.py)): 点の印はどのガイドも `anchors` (乗っている点はひし形)。点のドラッグの
プレビューは `moved_path` で作る。選んだ点の端からの伸ばし・「区間」のボタン・閉じたガイドのホイールはどのガイドでも。

**テストの書き換え**: 前の持ち方の中身を見ていた確かめ方を、新しい持ち方の同じ動きに直した (つなぎ線の `ends` /
`stops` -> 点の `attach.host` / 中継点の `vertex`、`smooth` / `route` -> `segment_modes`、`set_curve_anchors` ->
`move_points`、輪の点は最初から 4 つ、フリーハンドの端も動かせる、輪も切り離せる)。`test_path_model` は、今の作り方で
作ったガイドを前の版の形に書き直したもの (`legacy_set`) を変換して確かめる。

## GUI の確認のあとの変更 (2026-10-20)

ユーザーの確認 (操作は問題なし) と要望から:

- **途中の乗った点も外せる**: 乗った端から伸ばすと、乗った点が途中に残る (ひし形。途中でも付いて行く。この使い方は
  そのまま)。前は外せるのが端だけだったので、乗った点なら端でも途中でも、乗っているガイドから離れた所 (画面で
  `PICK_PIXELS` x 3) へドラッグすると外れるようにした (`tool/context._end_attach`。乗せるのは今までどおり開いた線の
  端だけ)。テスト: `test_bridge.case_detach_middle_point`
